# Security Policy

CatSense V0 is a prototype research project. It is not a medical device, safety
device, production pet tracker, or alarm system.

## Reporting Issues

Please report security or privacy issues privately to the project maintainer
before publishing details. If no private contact is listed on the repository,
open a minimal GitHub issue that describes the affected area without including
private data, tokens, home network details, or sample recordings.

## Data Privacy

Do not include private raw recordings, cat names, home notes, Wi-Fi details,
device identifiers, photos, or videos in public reports unless they were
deliberately prepared for public release.

## Supported Versions

Only the latest `main` branch is considered for security and privacy fixes.

# 开源准备

CatSense V0 计划开源，但猫咪和家庭环境数据需要谨慎处理。

## 项目定位

建议对外说明：

CatSense V0 是一个猫咪项圈 IMU 行为数据采集和建模原型，用于研究和开源协作。它不是医疗设备，不是安全设备，也不是量产宠物追踪器。

## 可以提交到仓库

- 固件源码
- Python 网关源码
- 网页采集器源码
- 训练脚本
- 文档
- 小型匿名示例 CSV
- 合成测试数据
- 模型格式说明

## 默认不提交

- 私人原始采集数据
- 大型处理后数据集
- 猫的真实名字
- 家庭位置、Wi-Fi、设备私有信息
- 视频和照片
- 本地虚拟环境
- `.pio` 构建缓存

当前 `.gitignore` 已排除：

```text
data/raw/*
data/processed/*
models/*
.venv/
.pio/
```

仓库保留 `data/raw/.gitkeep`、`data/processed/.gitkeep` 和 `models/.gitkeep` 作为目录占位。公开示例数据放在 `examples/synthetic/`，不要把私人数据移动到示例目录。

## 发布前仍建议确认

- 添加真实硬件照片或结构图，确认照片不泄露家庭环境。
- 从干净 checkout 验证 `make setup`、`make check` 和 `make firmware`。
- 从干净 venv 验证网页采集器运行。
- 如需发布真实样例数据，按下面的自采样例数据要求单独准备。

## 自采样例数据要求

发布任何自采真实样例数据前需要：

- 匿名 `cat_id`
- 移除私人备注
- 记录佩戴位置和松紧程度
- 记录大致采集环境，但不要泄露家庭隐私
- 明确数据贡献者同意
- 避免默认发布视频和照片

## 建议 Issue

适合新贡献者：

- 增加 session metadata 表单
- 扩展合成示例数据集
- 增加网页截图
- 改进数据质量报告
- 改进按 session 或日期划分的模型评估
- 增加模型版本号
- 增加 RSSI 或连接质量显示
- 增加更多硬件安装说明

## 贡献原则

- 保持 V0 简单可复现
- 不引入不必要的云服务
- 不提交私人数据
- 修改采集格式时同步更新协议文档
- 修改标签集合时同步更新数据和模型文档
- 模型效果必须说明评估方式
